
# Tomato Industry User Guide

## 1. Campaign Mode
- **Season**: typically July - October.
- **Pre-Campaign**: Ensure Steam Boiler meters are calibrated (Task generated in June).

## 2. Biomass Zero-Rating
- **Requirement**: Tomato residues/peels used as fuel must be RED II compliant.
- **Action**: Upload "Sustainability Certificate" in Evidence Vault.
- **Result**: Emissions from biomass count as 0 tCO2.

## 3. Monthly Routine (Campaign)
- Enter Natural Gas consumption for Steam Boilers.
- Enter Biomass tonnage consumed.
- Enter Production output (tonnes of tomato concentrate).

## 4. Off-Season
- Switch installation status to "Maintenance/Low Activity".
- Monitor "Specific Emissions" metric to ensure boiler efficiency doesn't drop during start-up/shut-down cycles.
