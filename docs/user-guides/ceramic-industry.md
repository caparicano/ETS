
# Ceramic Industry User Guide

## 1. Setup
- Upload your **TEGEH** permit PDF.
- Confirm Kilns (Tunnel, Roller) and Dryers.
- Define Carbonate sources (Raw Clay, Additives).

## 2. Monthly Routine
- **Combustion**: Enter natural gas meter readings (Nm³) for each kiln.
- **Process Emissions**: 
  - Enter clay consumption (tonnes).
  - Upload quarterly lab analysis for CaCO3 content (ISO 17025).

## 3. Annual Reporting (Jan-Mar)
1. **Data Check**: Ensure all 12 months are closed.
2. **Generate Draft**: Click "Generate RE Draft" in dashboard.
3. **Verification**: 
   - Go to "Verifier Access".
   - Generate link for your auditor (e.g., auditor@apcer.pt).
   - Send link via email.
4. **Submission**: Once verified, download XML for SILiAmb.

## 4. Strategic Planning
- Use the **Advisory** tab to ask about "Electrification of Tunnel Kilns".
- Check **Dashboard** for Free Allocation vs Emissions forecast.
