# Ecrã: Overview

Código do ecrã: `LANDING` · Menu: "Overview"

## Para que serve
Página inicial. Apresenta o que a aplicação faz: verificação de conformidade, otimização de processo (fornos, combustíveis) e estratégia de mercado (compra de licenças).

## O que há no ecrã
- Três cartões informativos: "Compliance Check", "Process Optimization" e "Market Strategy". São só informativos, não se clicam.
- Botão **"Start Consultation"**: abre o ecrã "AI Consultant".

## Por onde começar (sugestão para utilizadores novos)
1. "Strategy & Data" → "Setup New Installation", para configurar a instalação a partir do TEGEH.
2. "Compliance Tool", para ver as tarefas e registar consumos mensais.
3. "Compliance Tool" → separador "Evidence Vault", para carregar faturas e análises.
4. "AI Consultant", para dúvidas sobre regras.
