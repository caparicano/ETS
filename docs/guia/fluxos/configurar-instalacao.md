# Fluxo: configurar uma instalação nova

1. Abrir **"Strategy & Data"** no menu.
2. Clicar em **"Setup New Installation"**.
3. Clicar em **"Select PDF File"** e escolher o PDF do TEGEH.
4. Responder às perguntas do assistente (equipamentos e combustíveis).
5. Rever a pré-visualização ("Configuration Ready"): "Back to Edit" para corrigir, ou **"Approve & Create"** para concluir.

Nesta versão de demonstração, o assistente responde com dados de exemplo e entende "yes" e "gas" (ver o manual "Setup New Installation").
